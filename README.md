## 🌟 TÍNH NĂNG NỔI BẬT

1. **Âm nhạc nền trang nghiêm**:
   - Tích hợp bài ca bất hủ *"Huyền thoại Mẹ"* (sáng tác: Cố nhạc sĩ Trịnh Công Sơn) với nút bật/tắt đĩa than xoay nhẹ và thanh sóng nhạc (equalizer) sinh động.
2. **Không gian dâng hương tri ân (120% Signature Marquee Detail)**:
   - Lư hương đồng cổ kính với làn khói hương uốn lượn bay nhẹ (vẽ qua HTML5 Canvas thời gian thực).
   - Nút **"Thắp nén tâm hương"** tích hợp âm thanh chuông chùa ngân trầm thanh tịnh (Web Audio API Synthesizer) và hiệu ứng haptic rung nhẹ trên điện thoại thông minh.
   - Bộ đếm thời gian thực số lượt thắp nến của nhân dân cả nước.
3. **Danh mục 7 Mẹ VNAH Phường Hưng Phú (Đợt 1)**:
   - Hồ sơ số hóa sắc nét từ Bằng danh hiệu của Chủ tịch nước và Ảnh chân dung của Mẹ.
   - Tìm kiếm nhanh tức thì theo tên Mẹ, tên thân nhân là Liệt sĩ, quê quán, nơi thờ cúng / phụng dưỡng.
   - Bộ lọc phân loại: Tất cả (7 Mẹ), Có ảnh chân dung, Phong tặng (2 Mẹ), Truy tặng (5 Mẹ).
   - Hộp tiếp nhận tư liệu một chạm mở email gửi trực tiếp về Ban Chấp hành Đoàn phường.
4. **Hồ sơ Ký ức chi tiết (Chuẩn Mobile 3-Zone Flexbox)**:
   - Header cố định, nội dung cuộn trơn tru, footer tối ưu vùng an toàn ngón tay cái (`safe-area-inset-bottom` trên iPhone).
   - Cho phép phóng to xem toàn văn Bằng truy tặng/phong tặng hoặc Chân dung Mẹ độ nét cao.
   - Tích hợp nút *"Thắp hương dâng riêng Mẹ"*.
   - Nút *"Gửi tư liệu về Mẹ qua Email"* tự động điền sẵn tiêu đề và nội dung theo từng Mẹ.
5. **Sổ lưu bút tri ân trực tuyến**:
   - Cho phép đoàn viên, học sinh và nhân dân khắp mọi miền gửi lời tri ân sâu sắc.
   - Hỗ trợ đồng bộ đám mây qua **Google Cloud Firestore (Miễn phí 100%)** và tự động có chế độ dự phòng **LocalStorage** chạy ngay tức thì.
6. **Chuẩn Responsive Đa thiết bị**:
   - Tối ưu mượt mà từ iPhone, Android đến iPad và Desktop màn hình lớn.

## 🚀 HƯỚNG DẪN TRIỂN KHAI VERCEL MIỄN PHÍ 100%

### Bước 1: Đẩy mã nguồn lên GitHub
```bash
git add .
git commit -m "feat: Xây dựng hoàn chỉnh website Trạm Ký Ức Mẹ VNAH Phường Hưng Phú"
git push -u origin main
```

### Bước 2: Deploy lên Vercel
1. Truy cập [vercel.com](https://vercel.com) và đăng nhập bằng tài khoản GitHub.
2. Chọn **Add New...** $\rightarrow$ **Project**.
3. Chọn repository **`tram-ky-uc-phuong-hung-phu`** và bấm **Import**.
4. Bấm **Deploy** (giữ cấu hình mặc định).
5. Website sẽ hoạt động chính thức trong vòng chưa đầy 1 phút.

## ☁️ HƯỚNG DẪN KẾT NỐI FIREBASE FIRESTORE (TÙY CHỌN)

Nếu muốn đồng bộ số lượt thắp nến và lưu bút thời gian thực trên mây:
1. Tạo project trên [Firebase Console](https://console.firebase.google.com).
2. Tạo **Firestore Database** (location `asia-southeast1`).
3. Điền cấu hình vào `js/firebase-config.js` (`FIREBASE_CONFIG`).
4. Hệ thống sẽ tự động chuyển từ LocalStorage sang Firestore.
